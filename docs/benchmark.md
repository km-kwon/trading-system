# 벤치마크

벤치마크는 core matching path가 구현된 뒤 추가합니다. 현재 1단계에서는 측정 항목과 기록 원칙만 정의합니다.

## 예정 측정 항목

- 초당 처리 주문 수
- 체결 건수
- 거래량
- 거래대금
- VWAP
- p50 latency
- p95 latency
- p99 latency

## 기록 원칙

벤치마크 결과는 재현 가능해야 합니다. 결과 문서에는 다음 정보를 함께 남깁니다.

- 컴파일러 종류와 버전
- 빌드 타입
- CPU와 메모리 환경
- 주문 입력 시나리오
- 총 주문 수
- 체결 발생 비율
- 측정 시간과 반복 횟수

초기 목표는 과한 최적화가 아니라 정확한 기준선 확보입니다. lock-free 구조나 custom memory pool은 core correctness가 검증된 뒤에만 검토합니다.
